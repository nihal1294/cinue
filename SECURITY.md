# Security Policy

## Supported version

Security fixes target the latest commit on `main` until tagged releases begin.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for an unpatched vulnerability and do not include credentials, personal viewing data, or destructive proof-of-concept files.

Include the affected commit, reachable entry point, impact, and the smallest safe reproduction. You can expect an acknowledgement within seven days.
